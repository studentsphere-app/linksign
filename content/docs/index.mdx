Welcome to the documentation for linksign, a modern, lightweight, and zero-dependency TypeScript wrapper designed to interact with Edusign portals.

This project is entirely maintained by the [StudentSphere](https://github.com/studentsphere-app) team with the goal of providing open interoperability of digital student tools for everyone.

## Key Features

* 🔑 **Authentication**
* 📅 **Planning & Timetable Retrieval**
* ✔️ **Attendance Statistics & Presences**
* 🗺️ **Campus Map & Document Access**
* 🪶 **Zero Dependencies**
* ⚡ **TypeScript First**
* 🏫 **White Label Apps Support**

## Installation

### With yarn


## Quick Start

Here is a quick example showing how to authenticate a user, fetch their profile, and retrieve their schedule:

```typescript
import { loginWithCredentials, getPlanning, getProfile } from 'linksign';

async function run() {
  // 1. Authenticate with the CAS server and retrieve session token
  const user = await loginWithCredentials('epsi', 'john.doe', 'my_secure_password');
  console.log(`Hello, ${user.firstname} ${user.lastname}!`);

  // 2. Fetch the student's profile attributes
  const profile = await getProfile('epsi', user.token);
  console.log(`Email: ${profile.email}, Campus: ${profile.city}`);

  // 3. Fetch the student's planning lessons
  const lessons = await getPlanning('epsi', user.token);
  console.log(`Retrieved ${lessons.length} lessons.`);
}

run().catch(console.error);
```
