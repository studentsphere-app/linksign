This page documents the functionalities provided by the `planning.ts` file.

## Exported Functions

- `getPlanning`
- `getCoursesBetweenDates`
- `getCourseByCode`

## Example Usage

```typescript
import { getPlanning, getCoursesBetweenDates, getCourseByCode } from "@studentsphere/linksign";

async function run() {
  const planning = await getPlanning('YOUR_TOKEN');
  console.log(planning);

  const coursesBetweenDates = await getCoursesBetweenDates('YOUR_TOKEN');
  console.log(coursesBetweenDates);

  const courseByCode = await getCourseByCode('YOUR_TOKEN');
  console.log(courseByCode);
}

run().catch(console.error);
```
