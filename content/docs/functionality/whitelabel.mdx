title: Whitelabel
description: Documentation for the whitelabel service.
---

Edusign offers some schools a dedicated application that is essentially a white-labeled version of Edusign, branded with the school's colors and logo. 

This service allows you to retrieve the specific configuration of a white-label application and its SSO (Single Sign-On) configurations, making it easy to authenticate users through their specific institution's portal.

## Exported Functions

- [`getWhiteLabelConfiguration`](/docs/functions/whitelabel/getWhiteLabelConfiguration)
- [`getWhiteLabelSchools`](/docs/functions/whitelabel/getWhiteLabelSchools)

## Example Usage

```typescript
import {
  getWhiteLabelConfiguration,
  getWhiteLabelSchools,
} from "@studentsphere/linksign";

async function run() {
  const appPackage = "com.edusign.myedhec";

  // 1. Fetch white-label application configuration
  const configuration = await getWhiteLabelConfiguration(appPackage);
  console.log(configuration);

  // 2. Fetch schools supported by this white-label application
  const schools = await getWhiteLabelSchools(appPackage);
  console.log(schools);
}

run().catch(console.error);
```
