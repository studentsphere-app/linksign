This page documents the functionalities provided by the `schools` service.

## Exported Functions

- [`getSchools`](/docs/functions/schools/getSchools)
- [`getSchoolFeatures`](/docs/functions/schools/getSchoolFeatures)

## Example Usage

```typescript
import { getSchools, getSchoolFeatures } from "@studentsphere/linksign";

async function run() {
  // 1. Fetch schools linked to the authentication token
  const schools = await getSchools("YOUR_TOKEN", "OPTIONAL_DEVICE_ID");
  console.log(schools);

  // 2. Fetch enabled features and configurations for a specific school
  const schoolFeatures = await getSchoolFeatures(
    "YOUR_TOKEN",
    "SCHOOL_ID",
    "OPTIONAL_DEVICE_ID"
  );
  console.log(schoolFeatures);
}

run().catch(console.error);
```
