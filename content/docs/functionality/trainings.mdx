This page documents the functionalities provided by the `trainings` service.

## Exported Functions

- [`getTrainings`](/docs/functions/trainings/getTrainings)

## Example Usage

```typescript
import { getTrainings } from "@studentsphere/linksign";

async function run() {
  // Fetch trainings associated with the authenticated student
  const trainings = await getTrainings("YOUR_TOKEN", "OPTIONAL_DEVICE_ID");
  console.log(trainings);
}

run().catch(console.error);
```
