This page documents the functionalities provided by the `newsfeed` service.

## Exported Functions

- [`getPublicNewsFeedChannels`](/docs/functions/newsfeed/getPublicNewsFeedChannels)
- [`getPrivateNewsFeedChannels`](/docs/functions/newsfeed/getPrivateNewsFeedChannels)
- [`getPublicNewsFeedPosts`](/docs/functions/newsfeed/getPublicNewsFeedPosts)
- [`getPrivateNewsFeedPosts`](/docs/functions/newsfeed/getPrivateNewsFeedPosts)

## Example Usage

```typescript
import {
  getPublicNewsFeedChannels,
  getPrivateNewsFeedChannels,
  getPublicNewsFeedPosts,
  getPrivateNewsFeedPosts,
} from "@studentsphere/linksign";

async function run() {
  const schoolId = "SCHOOL_ID";

  // 1. Fetch public newsfeed channels
  const publicChannels = await getPublicNewsFeedChannels(schoolId, "fr");
  console.log(publicChannels);

  // 2. Fetch private newsfeed channels (authenticated)
  const privateChannels = await getPrivateNewsFeedChannels(
    schoolId,
    "YOUR_TOKEN",
    "OPTIONAL_DEVICE_ID",
    "fr"
  );
  console.log(privateChannels);

  // 3. Fetch public newsfeed posts
  const publicPosts = await getPublicNewsFeedPosts(
    schoolId,
    { channels: ["CHANNEL_ID_1"], limit: 10 },
    "fr"
  );
  console.log(publicPosts);

  // 4. Fetch private newsfeed posts (authenticated)
  const privatePosts = await getPrivateNewsFeedPosts(
    schoolId,
    "YOUR_TOKEN",
    { channels: ["CHANNEL_ID_1"], limit: 10 },
    "OPTIONAL_DEVICE_ID",
    "fr"
  );
  console.log(privatePosts);
}

run().catch(console.error);
```
