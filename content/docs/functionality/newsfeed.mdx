This page documents the functionalities provided by the `newsfeed.ts` file.

## Exported Functions

- `getPublicNewsFeedChannels`
- `getPrivateNewsFeedChannels`
- `getPublicNewsFeedPosts`
- `getPrivateNewsFeedPosts`

## Example Usage

```typescript
import { getPublicNewsFeedChannels, getPrivateNewsFeedChannels, getPublicNewsFeedPosts, getPrivateNewsFeedPosts } from "@studentsphere/linksign";

async function run() {
  const publicNewsFeedChannels = await getPublicNewsFeedChannels('YOUR_TOKEN');
  console.log(publicNewsFeedChannels);

  const privateNewsFeedChannels = await getPrivateNewsFeedChannels('YOUR_TOKEN');
  console.log(privateNewsFeedChannels);

  const publicNewsFeedPosts = await getPublicNewsFeedPosts('YOUR_TOKEN');
  console.log(publicNewsFeedPosts);

  const privateNewsFeedPosts = await getPrivateNewsFeedPosts('YOUR_TOKEN');
  console.log(privateNewsFeedPosts);
}

run().catch(console.error);
```
