This page documents the functionalities provided by the `knowledgebase` service.

## Exported Functions

- [`getPublicKnowledgeBasePosts`](/docs/functions/knowledgebase/getPublicKnowledgeBasePosts)
- [`getPrivateKnowledgeBasePosts`](/docs/functions/knowledgebase/getPrivateKnowledgeBasePosts)

## Example Usage

```typescript
import {
  getPublicKnowledgeBasePosts,
  getPrivateKnowledgeBasePosts,
} from "@studentsphere/linksign";

async function run() {
  const schoolId = "SCHOOL_ID";

  // Fetch public knowledge base articles
  const publicPosts = await getPublicKnowledgeBasePosts(schoolId);
  console.log(publicPosts);

  // Fetch private/authenticated knowledge base articles
  const privatePosts = await getPrivateKnowledgeBasePosts(
    schoolId,
    "YOUR_TOKEN",
    "OPTIONAL_DEVICE_ID"
  );
  console.log(privatePosts);
}

run().catch(console.error);
```
