This page documents the functionalities provided by the `documents` service.

## Exported Functions

- [`getDocuments`](/docs/functions/documents/getDocuments)
- [`getStudentAttachments`](/docs/functions/documents/getStudentAttachments)
- [`getProfessors`](/docs/functions/documents/getProfessors)

## Example Usage

```typescript
import {
  getDocuments,
  getStudentAttachments,
  getProfessors,
} from "@studentsphere/linksign";

async function run() {
  // Fetch school administrative documents
  const documents = await getDocuments("YOUR_TOKEN", "OPTIONAL_DEVICE_ID");
  console.log(documents);

  // Fetch student attachments and certificates
  const attachments = await getStudentAttachments(
    "YOUR_TOKEN",
    "OPTIONAL_DEVICE_ID"
  );
  console.log(attachments);

  // Fetch professor details by an array of IDs
  const professors = await getProfessors(
    "YOUR_TOKEN",
    ["PROFESSOR_ID_1", "PROFESSOR_ID_2"],
    "OPTIONAL_DEVICE_ID"
  );
  console.log(professors);
}

run().catch(console.error);
```
