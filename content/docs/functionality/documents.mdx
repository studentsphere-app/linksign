This page documents the functionalities provided by the `documents.ts` file.

## Exported Functions

- `getDocuments`
- `getStudentAttachments`
- `getProfessors`

## Example Usage

```typescript
import { getDocuments, getStudentAttachments, getProfessors } from "@studentsphere/linksign";

async function run() {
  const documents = await getDocuments('YOUR_TOKEN');
  console.log(documents);

  const studentAttachments = await getStudentAttachments('YOUR_TOKEN');
  console.log(studentAttachments);

  const professors = await getProfessors('YOUR_TOKEN');
  console.log(professors);
}

run().catch(console.error);
```
