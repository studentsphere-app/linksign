This page documents the functionalities provided by the `assessments` service.

## Exported Functions

- [`getAssessments`](/docs/functions/assessments/getAssessments)
- [`getAssessmentDetailById`](/docs/functions/assessments/getAssessmentDetailById)

## Example Usage

```typescript
import { getAssessments, getAssessmentDetailById } from "@studentsphere/linksign";

async function run() {
  // Fetch upcoming/future assessments
  const assessments = await getAssessments("YOUR_TOKEN", "future", "OPTIONAL_DEVICE_ID");
  console.log(assessments);

  // Fetch detailed assessment information by ID
  const assessmentDetail = await getAssessmentDetailById(
    "YOUR_TOKEN",
    "ASSESSMENT_ID",
    "OPTIONAL_DEVICE_ID"
  );
  console.log(assessmentDetail);
}

run().catch(console.error);
```
