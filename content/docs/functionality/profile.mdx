This page documents the functionalities provided by the `profile.ts` file.

## Exported Functions

- `getProfile`
- `getSchoolsByToken`
- `getNotificationsPreferences`

## Example Usage

```typescript
import { getProfile, getSchoolsByToken, getNotificationsPreferences } from "@studentsphere/linksign";

async function run() {
  const profile = await getProfile('YOUR_TOKEN');
  console.log(profile);

  const schoolsByToken = await getSchoolsByToken('YOUR_TOKEN');
  console.log(schoolsByToken);

  const notificationsPreferences = await getNotificationsPreferences('YOUR_TOKEN');
  console.log(notificationsPreferences);
}

run().catch(console.error);
```
