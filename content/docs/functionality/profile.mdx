This page documents the functionalities provided by the `profile` service.

## Exported Functions

- [`getProfile`](/docs/functions/profile/getProfile)
- [`getSchoolsByToken`](/docs/functions/profile/getSchoolsByToken)
- [`getNotificationsPreferences`](/docs/functions/profile/getNotificationsPreferences)

## Example Usage

```typescript
import {
  getProfile,
  getSchoolsByToken,
  getNotificationsPreferences,
} from "@studentsphere/linksign";

async function run() {
  // 1. Fetch current student profile
  const profile = await getProfile("YOUR_TOKEN", "OPTIONAL_DEVICE_ID");
  console.log(profile);

  // 2. Fetch associated school accounts for this token
  const schools = await getSchoolsByToken("YOUR_TOKEN", "OPTIONAL_DEVICE_ID");
  console.log(schools);

  // 3. Fetch user notification preferences
  const preferences = await getNotificationsPreferences(
    "YOUR_TOKEN",
    "OPTIONAL_DEVICE_ID"
  );
  console.log(preferences);
}

run().catch(console.error);
```
