This page documents the functionalities provided by the `campusmap` service.

## Exported Functions

- [`getPublicCampusMapBySchool`](/docs/functions/campusmap/getPublicCampusMapBySchool)
- [`getPrivateCampusMapBySchool`](/docs/functions/campusmap/getPrivateCampusMapBySchool)

## Example Usage

```typescript
import {
  getPublicCampusMapBySchool,
  getPrivateCampusMapBySchool,
} from "@studentsphere/linksign";

async function run() {
  const schoolId = "SCHOOL_ID";

  // Fetch public campus map locations
  const publicMap = await getPublicCampusMapBySchool(schoolId);
  console.log(publicMap);

  // Fetch private/authenticated campus map locations
  const privateMap = await getPrivateCampusMapBySchool(
    schoolId,
    "YOUR_TOKEN",
    "OPTIONAL_DEVICE_ID"
  );
  console.log(privateMap);
}

run().catch(console.error);
```
