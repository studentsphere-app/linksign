This page documents the functionalities provided by the `campusmap.ts` file.

## Exported Functions

- `getPublicCampusMapBySchool`
- `getPrivateCampusMapBySchool`

## Example Usage

```typescript
import { getPublicCampusMapBySchool, getPrivateCampusMapBySchool } from "@studentsphere/linksign";

async function run() {
  const publicCampusMapBySchool = await getPublicCampusMapBySchool('YOUR_TOKEN');
  console.log(publicCampusMapBySchool);

  const privateCampusMapBySchool = await getPrivateCampusMapBySchool('YOUR_TOKEN');
  console.log(privateCampusMapBySchool);
}

run().catch(console.error);
```
