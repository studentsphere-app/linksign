## Usage

```typescript
import { getAbsences } from "@studentsphere/linksign";

async function run() {
  const result = await getAbsences('YOUR_TOKEN', 'start', 'end', 'OPTIONAL_DEVICE_ID');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[Absence](/docs/types/attendance#absence-interface)[]** object.
