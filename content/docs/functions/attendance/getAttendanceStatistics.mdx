## Usage

```typescript
import { getAttendanceStatistics } from "@studentsphere/linksign";

async function run() {
  const result = await getAttendanceStatistics('YOUR_TOKEN', 'start', 'end', 'TRAINING_ID', 'OPTIONAL_DEVICE_ID');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[AttendanceStatistics](/docs/types/attendance#attendancestatistics-interface)** object.
