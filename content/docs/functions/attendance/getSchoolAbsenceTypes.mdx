<TypeTable

## Usage

```typescript
import { getSchoolAbsenceTypes } from "@studentsphere/linksign";

async function run() {
  const result = await getSchoolAbsenceTypes('YOUR_TOKEN', 'OPTIONAL_DEVICE_ID');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[SchoolAbsenceType](/docs/types/attendance#schoolabsencetype-interface)[]** object.
