## Usage

```typescript
import { loginWithMicrosoft } from "@studentsphere/linksign";

async function run() {
  const result = await loginWithMicrosoft('AUTH_CODE', true, 'OPTIONAL_DEVICE_ID');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[MicrosoftOauthAuthSession](/docs/types/auth#microsoftoauthauthsession-interface)** object.
