## Usage

```typescript
import { loginWithMicrosoftSso } from "@studentsphere/linksign";

async function run() {
  const result = await loginWithMicrosoftSso('AUTH_CODE', true, 'OPTIONAL_DEVICE_ID');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[MicrosoftSsoAuthSession](/docs/types/auth#microsoftssoauthsession-type)** object.
