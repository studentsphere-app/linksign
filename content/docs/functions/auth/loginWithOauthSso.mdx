This page documents the `loginWithOauthSso` function from the `@studentsphere/linksign` library.

<TypeTable
  type={{

## Usage

```typescript
import { loginWithOauthSso } from "@studentsphere/linksign";

async function run() {
  const result = await loginWithOauthSso('AUTH_CODE', 'SCHOOL_ID', 'OPTIONAL_DEVICE_ID');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[OauthSsoAuthSession](/docs/types/auth#oauthssoauthsession-type)** object.
