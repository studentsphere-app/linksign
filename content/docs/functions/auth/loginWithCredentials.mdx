## Usage

```typescript
import { loginWithCredentials } from "@studentsphere/linksign";

async function run() {
  const result = await loginWithCredentials('IDENTIFIER', 'password123', "fr", 'OPTIONAL_DEVICE_ID');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[AuthSession](/docs/types/auth#authsession-interface)** object.
