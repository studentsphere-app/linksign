<TypeTable

## Usage

```typescript
import { getSsoConfig } from "@studentsphere/linksign";

async function run() {
  const result = await getSsoConfig('domain');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[SsoConfig](/docs/types/auth#ssoconfig-type)** object.
