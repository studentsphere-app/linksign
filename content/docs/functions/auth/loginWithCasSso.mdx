## Usage

```typescript
import { loginWithCasSso } from "@studentsphere/linksign";

async function run() {
  const result = await loginWithCasSso('ticket', 'SCHOOL_ID', true, 'OPTIONAL_DEVICE_ID');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[CasSsoAuthSession](/docs/types/auth#casssoauthsession-type)** object.
