## Usage

```typescript
import { isSsoEnabled } from "@studentsphere/linksign";

async function run() {
  const result = await isSsoEnabled('student@school.com');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **boolean** object.
