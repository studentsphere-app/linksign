## Usage

```typescript
import { loginWhitelabelAppWithCredentials } from "@studentsphere/linksign";

async function run() {
  const result = await loginWhitelabelAppWithCredentials('IDENTIFIER', 'password123', 'SCHOOL_ID', "fr", 'OPTIONAL_DEVICE_ID');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[AuthSession](/docs/types/auth#authsession-interface)** object.
