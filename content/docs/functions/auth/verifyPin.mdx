## Usage

```typescript
import { verifyPin } from "@studentsphere/linksign";

async function run() {
  const result = await verifyPin('IDENTIFIER', '1234');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[PinVerification](/docs/types/auth#pinverification-interface)** object.
