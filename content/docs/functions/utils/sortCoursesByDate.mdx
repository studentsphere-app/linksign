<TypeTable
  type={{

## Usage

```typescript
import { sortCoursesByDate } from "@studentsphere/linksign";

const result = sortCoursesByDate([
  { 
    ID: "ep98mpyt9yqfyez", 
    NAME: "Web Development", 
    START: "2026-09-01T08:00:00Z", 
    END: "2026-09-01T10:00:00Z", 
    IS_ABSENT: false, 
    STATUS: "Present" 
  },
  { 
    ID: "ep52mpyy9yqbyen", 
    NAME: "Software Architecture", 
    START: "2026-09-02T14:00:00Z", 
    END: "2026-09-02T16:00:00Z", 
    IS_ABSENT: true, 
    STATUS: "Absent" 
  }
], "asc");
console.log(result);
```

## Return Value

Returns a **[CourseEntry](/docs/types/planning#courseentry-interface)[]** object.
