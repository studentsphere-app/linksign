This page documents the `getTodayCourses` function from the `@studentsphere/linksign` library.

## Parameters

<TypeTable
  type={{
    courses: {
      type: `CourseEntry[]`,
      description: "Courses",
    },
  }}
/>

## Usage

```typescript
import { getTodayCourses } from "@studentsphere/linksign";

const result = getTodayCourses([
  { 
    ID: "ep98mpyt9yqfyez", 
    NAME: "Web Development", 
    START: "2026-09-01T08:00:00Z", 
    END: "2026-09-01T10:00:00Z", 
    IS_ABSENT: false, 
    STATUS: "Present" 
  },
  { 
    ID: "ep52mpyy9yqbyen", 
    NAME: "Software Architecture", 
    START: "2026-09-02T14:00:00Z", 
    END: "2026-09-02T16:00:00Z", 
    IS_ABSENT: true, 
    STATUS: "Absent" 
  }
]);
console.log(result);
```

## Return Value

Returns a **[CourseEntry](/docs/types/planning#courseentry-interface)[]** object.
