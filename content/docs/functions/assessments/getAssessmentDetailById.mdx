## Usage

```typescript
import { getAssessmentDetailById } from "@studentsphere/linksign";

async function run() {
  const result = await getAssessmentDetailById('YOUR_TOKEN', 'ID', 'OPTIONAL_DEVICE_ID');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[AssessmentDetail](/docs/types/assessments#assessmentdetail-interface)** object.
