## Usage

```typescript
import { getAssessments } from "@studentsphere/linksign";

async function run() {
  const result = await getAssessments('YOUR_TOKEN', 'future', 'OPTIONAL_DEVICE_ID');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[Assessments](/docs/types/assessments#assessments-type)** object.
