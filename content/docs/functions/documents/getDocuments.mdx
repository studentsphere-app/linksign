This page documents the `getDocuments` function from the `@studentsphere/linksign` library.

## Parameters

<TypeTable
  type={{
    token: {
      type: `string`,

    },
    deviceId: {
      type: `string`,

## Usage

```typescript
import { getDocuments } from "@studentsphere/linksign";

async function run() {
  const result = await getDocuments('YOUR_TOKEN', 'OPTIONAL_DEVICE_ID');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[Documents](/docs/types/documents#documents-interface)&lt;[SchoolDocument](/docs/types/documents#schooldocument-interface)&gt;** object.
