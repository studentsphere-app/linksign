## Usage

```typescript
import { getPublicNewsFeedChannels } from "@studentsphere/linksign";

async function run() {
  const result = await getPublicNewsFeedChannels('SCHOOL_ID', 'lang');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[NewsFeedChannel](/docs/types/newsfeed#newsfeedchannel-interface)[]** object.
