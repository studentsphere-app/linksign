## Usage

```typescript
import { getPrivateNewsFeedChannels } from "@studentsphere/linksign";

async function run() {
  const result = await getPrivateNewsFeedChannels('SCHOOL_ID', 'YOUR_TOKEN', 'OPTIONAL_DEVICE_ID', 'lang');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[NewsFeedChannel](/docs/types/newsfeed#newsfeedchannel-interface)[]** object.
