## Usage

```typescript
import { getPrivateNewsFeedPosts } from "@studentsphere/linksign";

async function run() {
  const result = await getPrivateNewsFeedPosts('SCHOOL_ID', 'YOUR_TOKEN', { channels: ['1', '2'], limit: 10 }, 'OPTIONAL_DEVICE_ID', 'lang');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[NewsFeedPostsResponse](/docs/types/newsfeed#newsfeedpostsresponse-type)** object.
