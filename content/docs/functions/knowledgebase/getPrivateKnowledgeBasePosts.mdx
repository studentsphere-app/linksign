## Usage

```typescript
import { getPrivateKnowledgeBasePosts } from "@studentsphere/linksign";

async function run() {
  const result = await getPrivateKnowledgeBasePosts('SCHOOL_ID', 'YOUR_TOKEN', 'OPTIONAL_DEVICE_ID');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[KnowledgeBasePost](/docs/types/knowledgebase#knowledgebasepost-interface)[]** object.
