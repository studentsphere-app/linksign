## Usage

```typescript
import { getPrivateContactsDirectory } from "@studentsphere/linksign";

async function run() {
  const result = await getPrivateContactsDirectory('SCHOOL_ID', 'YOUR_TOKEN', 'OPTIONAL_DEVICE_ID', { name: 'John Doe', page: 1 });
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[PaginatedData](/docs/types/common#paginateddata-interface)&lt;[ContactDirectoryEntry](/docs/types/contactsdirectory#contactdirectoryentry-interface)&gt;** object.
