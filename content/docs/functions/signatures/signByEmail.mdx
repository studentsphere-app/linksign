## Usage

```typescript
import { signByEmail } from "@studentsphere/linksign";

async function run() {
  const result = await signByEmail('YOUR_TOKEN', 'COURSE_ID', 'verificationToken', { studentId: 'STUDENT_ID', schoolId: 'SCHOOL_ID', base64Signature: 'BASE64_STRING' }, 'OPTIONAL_DEVICE_ID');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **unknown** object.
