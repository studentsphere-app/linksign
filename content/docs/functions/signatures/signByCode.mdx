## Usage

```typescript
import { signByCode } from "@studentsphere/linksign";

async function run() {
  const result = await signByCode('YOUR_TOKEN', 'AUTH_CODE', { studentId: 'STUDENT_ID', base64Signature: 'BASE64_STRING' }, 'OPTIONAL_DEVICE_ID');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **unknown** object.
