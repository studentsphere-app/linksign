## Usage

```typescript
import { signByQRCode } from "@studentsphere/linksign";

async function run() {
  const result = await signByQRCode('YOUR_TOKEN', 'QR_CODE_ID', { signature: 'BASE64_STRING', courseId: 'COURSE_ID', UUID: 'UUID', Model: 'DEVICE_MODEL' }, 'OPTIONAL_DEVICE_ID');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **unknown** object.
