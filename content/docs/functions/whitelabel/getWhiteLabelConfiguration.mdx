## Parameters

<TypeTable
  type={{

      type: `string`,

    },
  }}

## Usage

```typescript
import { getWhiteLabelConfiguration } from "@studentsphere/linksign";

async function run() {
  const result = await getWhiteLabelConfiguration('appPackage');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[WhiteLabelAppConfiguration](/docs/types/whitelabel#whitelabelappconfiguration-interface)** object.
