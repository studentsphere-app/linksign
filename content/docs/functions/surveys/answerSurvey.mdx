## Usage

```typescript
import { answerSurvey } from "@studentsphere/linksign";

async function run() {
  const result = await answerSurvey('YOUR_TOKEN', 'SCHOOL_ID', 'STUDENT_ID', 'SURVEY_ID', { answers: { "question_1": "Response" } }, 'OPTIONAL_DEVICE_ID');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **unknown** object.
