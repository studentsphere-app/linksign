## Parameters

<TypeTable
  type={{
    token: {
      type: `string`,

## Usage

```typescript
import { getSurveys } from "@studentsphere/linksign";

async function run() {
  const result = await getSurveys('YOUR_TOKEN', 'OPTIONAL_DEVICE_ID');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[Surveys](/docs/types/surveys#surveys-interface)&lt;[SurveyEntry](/docs/types/surveys#surveyentry-interface)&gt;** object.
