## Usage

```typescript
import { getSurveyById } from "@studentsphere/linksign";

async function run() {
  const result = await getSurveyById('YOUR_TOKEN', 'SCHOOL_ID', 'STUDENT_ID', 'SURVEY_ID', 'OPTIONAL_DEVICE_ID');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[SurveyDetails](/docs/types/surveys#surveydetails-interface)** object.
