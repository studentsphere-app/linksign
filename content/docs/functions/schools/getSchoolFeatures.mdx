This page documents the `getSchoolFeatures` function from the `@studentsphere/linksign` library.

## Parameters

<TypeTable
  type={{
    token: {
      type: `string`,
      description: "Token",
    },
    schoolId: {
      type: `string`,
      description: "School id",
    },
    deviceId: {
      type: `string`,
      description: "Device id",
      optional: true,
    },
  }}
/>

## Usage

```typescript
import { getSchoolFeatures } from "@studentsphere/linksign";

async function run() {
  const result = await getSchoolFeatures('YOUR_TOKEN', 'SCHOOL_ID', 'OPTIONAL_DEVICE_ID');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[SchoolFeatures](/docs/types/schools#schoolfeatures-interface)** object.
