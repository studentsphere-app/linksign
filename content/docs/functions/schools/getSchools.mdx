This page documents the `getSchools` function from the `@studentsphere/linksign` library.

## Parameters

<TypeTable
  type={{
    token: {
      type: `string`,
      description: "Token",
    },
    deviceId: {
      type: `string`,
      description: "Device id",
      optional: true,
    },
  }}
/>

## Usage

```typescript
import { getSchools } from "@studentsphere/linksign";

async function run() {
  const result = await getSchools('YOUR_TOKEN', 'OPTIONAL_DEVICE_ID');
  console.log(result);
}

run().catch(console.error);
```

## Return Value

Returns a `Promise` resolving to a **[StudentAccount](/docs/types/schools#studentaccount-interface)[]** object.
